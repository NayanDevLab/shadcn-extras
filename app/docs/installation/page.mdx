# Installation

Shadcn-Extras components are **React + Tailwind CSS** and animated with **Motion**.  
Follow the steps below — they’re short and safe for existing projects.

<Steps>

<Step>Install Tailwind CSS (if you don’t have it yet)</Step>

Shadcn-Extras works with **Tailwind v3 or v4**.  
Follow the official guide if Tailwind isn’t set up:

- Tailwind v3: https://v3.tailwindcss.com/docs/installation
- Tailwind v4: https://tailwindcss.com/docs/installation/framework-guides

> If you already have Tailwind, you can skip this step.

<Step>Install Motion</Step>

All animations use <a href="https://motion.dev" target="_blank">Motion</a>.

<CodeBlock code={`npm install motion`} lang='bash' className='h-[52px]' />

<Step>Install Icons</Step>

Some examples use <a href="https://lucide.dev" target="_blank">Lucide</a>.

<CodeBlock code={`npm install lucide-react`} lang='bash' className='h-[52px]' />

<Step>Utility helper (only if you DON’T already have \`cn\`)</Step>

If your project already uses **shadcn/ui**, you likely have `cn` in `@/lib/utils`.  
**Skip this step** if `cn` already exists.

Otherwise, install small utilities and add the helper:

<CodeBlock
  code={`npm install clsx tailwind-merge`}
  lang='bash'
  className='h-[52px]'
/>

Create `lib/utils.ts`:

<CodeBlock
  lang="ts"
  code={`import { type ClassValue } from "clsx";
import clsx from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
`}
/>

<Step>Add your first component</Step>

Use the CLI to add a component into your project (files are copied so you can edit freely):

<InstallationCli value='kpi-card' />

This command will add **KPI Card** to your app (under \`components/\`).  
You can then import it anywhere in your project.

**Manual install?** You can also copy code directly from each component page.

</Steps>
