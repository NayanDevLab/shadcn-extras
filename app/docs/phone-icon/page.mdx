## Props

| Prop      | Type    | Default        | Description                    |
| --------- | ------- | -------------- | ------------------------------ |
| className | string  |                | Wrapper classes                |
| color     | string  | "currentColor" | Icon color                     |
| size      | number  | 24             | Icon size in pixels            |
| isRinging | boolean | false          | Controls the ringing animation |
