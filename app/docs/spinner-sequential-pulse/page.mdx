## Component API

### SpinnerSequentialPulse

| Prop       | Type    | Default | Description                         |
| :--------- | :------ | :------ | :---------------------------------- |
| size       | number  | 120     | Outer square size (px)              |
| count      | number  | 12      | Number of dots                      |
| dotSize    | number  | 8       | Dot diameter (px)                   |
| color      | string  | '#fff'  | Dot color                           |
| showTrack  | boolean | true    | Show faint outer ring               |
| trackColor | string  | rgba    | Track color                         |
| trackWidth | number  | 2       | Track thickness (px)                |
| showSpokes | boolean | true    | Show faint radial spokes            |
| speed      | number  | 1.2     | Full pulse cycle duration (seconds) |
| className  | string  |         | Tailwind classes on outer container |
