# Badge Generator

Create status badges — solid or soft-tinted, pill or rounded, with an optional status dot — and copy the JSX.

<div className='my-8'>
  <BadgeGenerator />
</div>

## Features

- **Soft mode**: tinted background with matching text, like modern dashboards.
- **Status dot**: optional pulse-ready indicator dot.
- **Shape & case**: pill or rounded corners, optional uppercase.
