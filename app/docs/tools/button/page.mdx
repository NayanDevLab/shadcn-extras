# Button Generator

Design a custom button visually — colors, radius, padding, shadow and hover effect — then copy the Tailwind classes or plain CSS.

<div className='my-8'>
  <ButtonGenerator />
</div>

## Features

- **Full visual control**: background, text color, radius, padding and font size.
- **Hover effects**: darken, lift or grow — with the transition classes included.
- **Two outputs**: Tailwind arbitrary-value classes or vanilla CSS.
