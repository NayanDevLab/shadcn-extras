# Card Generator

Design a card container — background, border, radius, padding, shadow and hover lift — and copy the ready-to-paste JSX.

<div className='my-8'>
  <CardGenerator />
</div>

## Features

- **Shadow presets**: none to xl, plus an optional hover-lift animation.
- **Border control**: width and color, from borderless to bold.
- **JSX output**: a complete card snippet with Tailwind classes.
