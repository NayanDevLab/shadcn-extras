# Scrollbar Generator

Style custom scrollbars — width, track, thumb, hover color and radius — test them in a live scrollable panel, and copy cross-browser CSS.

<div className='my-8'>
  <ScrollbarGenerator />
</div>

## Features

- **Live scroll test**: a real scrollable panel styled with your settings.
- **Cross-browser output**: WebKit `::-webkit-scrollbar` rules plus Firefox `scrollbar-color`.
- **Full control**: width, radius, track, thumb and hover colors.
