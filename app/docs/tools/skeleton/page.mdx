# Skeleton Generator

Build shimmer loading skeletons — line count, avatar, radius, speed and colors — with the keyframes CSS and JSX ready to copy.

<div className='my-8'>
  <SkeletonGenerator />
</div>

## Features

- **Layout options**: 1–6 text lines with an optional avatar circle.
- **Shimmer tuning**: animation speed plus base and highlight colors.
- **Two outputs**: the `@keyframes` CSS and a matching JSX layout.
