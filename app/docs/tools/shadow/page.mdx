# Shadow Generator

Build layered box-shadows visually — up to 4 layers with offset, blur, spread, color, opacity and inset — then copy the CSS or Tailwind arbitrary class.

<div className='my-8'>
  <ShadowGenerator />
</div>

## Features

- **Multi-layer shadows**: stack up to 4 layers for realistic depth.
- **Full control**: X/Y offset, blur, spread, per-layer color and opacity, inset support.
- **Two outputs**: `box-shadow` CSS or a Tailwind `shadow-[...]` arbitrary class.
