# Text Gradient Generator

Make headlines pop with gradient text — pick 2–3 colors and a direction, preview at any size, and copy the Tailwind classes.

<div className='my-8'>
  <TextGradientGenerator />
</div>

## Features

- **2 or 3 color stops** with four gradient directions.
- **Live text preview**: type your own headline and scale it up to 96px.
- **Two outputs**: `bg-clip-text` Tailwind classes or vanilla CSS.
