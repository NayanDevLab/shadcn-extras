# Input Generator

Style a text input with a live focus-ring preview — border, focus color, radius and sizing — then copy Tailwind classes or CSS.

<div className='my-8'>
  <InputGenerator />
</div>

## Features

- **Focus ring designer**: pick the focus color and ring width, test it live by clicking the input.
- **Complete styling**: border, background, text color, radius and height.
- **Two outputs**: Tailwind classes (with `focus:` variants) or vanilla CSS.
