# Glassmorphism Generator

Tune frosted-glass surfaces — blur, transparency, border, saturation and tint — over a colorful live backdrop, then copy the CSS.

<div className='my-8'>
  <GlassmorphismGenerator />
</div>

## Features

- **Realistic preview**: a colorful backdrop with blobs so you can actually see the blur.
- **Full control**: backdrop blur, background/border opacity, saturation boost and tint color.
- **Two outputs**: `backdrop-filter` CSS or Tailwind arbitrary classes.
