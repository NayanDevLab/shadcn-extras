## Props

| Prop        | Type     | Default      | Description                        |
| :---------- | :------- | :----------- | :--------------------------------- |
| `name`      | `string` | **Required** | The name of the reviewer.          |
| `role`      | `string` | **Required** | The role or title of the reviewer. |
| `content`   | `string` | **Required** | The testimonial text.              |
| `avatarSrc` | `string` | **Required** | The URL of the avatar image.       |
| `rating`    | `number` | `5`          | The star rating (0-5).             |
