# Newspaper Layout

A classic, vintage newspaper layout component featuring robust responsive flexbox grids and custom web typography. It perfectly adapts from a multi-column desktop spread to a single-column mobile view.

## Installation

```bash
npx shadcn-extras@latest add newspaper
```

## Props

The `NewspaperArticle` component accepts the following props:

| Prop         | Type      | Description                                                                                          |
| ------------ | --------- | ---------------------------------------------------------------------------------------------------- |
| `isBreaking` | `boolean` | If true, the article will take up twice as much horizontal space as a standard article (`flex-[2]`). |

## Features

- Handles responsive column stacking automatically.
- Imports `Oswald`, `Merriweather`, and a custom `Queens Park` font to achieve a genuine vintage newsprint aesthetic.
- Highly composable structure: `<Newspaper>`, `<NewspaperHeader>`, `<NewspaperContent>`, and `<NewspaperArticle>`.
